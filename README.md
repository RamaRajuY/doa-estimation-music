# Direction of Arrival Estimation Using MUSIC

This project implements Direction of Arrival (DOA) estimation
using the Multiple Signal Classification (MUSIC) algorithm.

## Objectives

- Model a Uniform Linear Array (ULA)
- Generate signals arriving from different directions
- Calculate the spatial covariance matrix
- Perform eigenvalue decomposition
- Separate signal and noise subspaces
- Calculate the MUSIC pseudospectrum
- Estimate the directions of arrival

## Technologies

- Python
- NumPy
- SciPy
- Matplotlib
